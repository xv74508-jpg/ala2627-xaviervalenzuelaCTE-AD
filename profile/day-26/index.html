Movement that earns its place

Add motion that helps someone read the page, and nothing that makes them wait.

Why this day exists

Movement is where a professional page and an amateur one separate fastest. The test is not whether it looks cool — it is whether removing it would make the page harder to use. Anything that fails that test comes out.

What you do

  1. States firstEvery clickable thing gets :hover and :focus-visible. Not decoration — the page telling someone what it does.
  2. One considered revealRead the example’s scroll reveal. Twelve lines, commented. Notice it only hides content once it knows it can show it again.
  3. Respect the settingWrap it in prefers-reduced-motion. Some people are made ill by movement on a screen. This is not optional politeness.
  4. Take one thing outWhatever you added that you like most: remove it and reload. If the page is no worse, leave it out.

Done when

Hover and focus on everything clickable, at most one reveal, switched off under reduced motion.
